```
Qoder 专家团架构：

┌─────────────────────────────────────────────────────────────┐
│                    Team Lead（团队领导）                      │
│    - 任务分解                                                │
│    - 专家调度                                                │
│    - 结果聚合                                                │
└─────────────────────────────────────────────────────────────┘
                         ↓
        ┌────────────────┼────────────────┐
        ↓                ↓                ↓
┌───────────────┐ ┌───────────────┐ ┌───────────────┐
│ 专家 1        │ │ 专家 2        │ │ 专家 N        │

```
